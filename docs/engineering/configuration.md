# Configuration reference

Generated literal variable usages. No values are read from private environment files. Runtime providers/defaults are explained in [AI and evidence](ai-and-evidence.md). Variables used only by preview plugins or historical migrations are not automatically required in production. Dynamic lookups can require additional variables; inspect the linked service.

Root Compose reads root `.env`. Direct web npm scripts read `apps/web/.env`; backend shell scripts depend on exported process environment. Required Compose variables are PocketBase encryption and superuser identity/password. The public URL and provider keys are deployment-specific.
